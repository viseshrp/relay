# Keyboard shortcuts

| Keys | Action |
| --- | --- |
| Cmd/Ctrl+S | Save the workflow and edited local instructions |
| Cmd/Ctrl+Z | Undo a visual workflow edit; inside YAML, undo text |
| Cmd/Ctrl+Shift+Z | Redo a workflow edit |
| Arrow keys | Move through the canvas job list |
| Escape | Close the current dialog or help popup |
| Tab / Shift+Tab | Move through controls and navigation links |

The first Tab stop is **Skip to content**. On a run, **Skip to summary** bypasses
its job list. Navigation links support browser new-tab commands and middle-click.
Use the searchable job list when drawing or zooming is inconvenient.

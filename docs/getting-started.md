# Getting started

Relay runs local coding workflows and keeps their results, logs, and approvals.

1. Open a Git repository using the project picker. Relay keeps workflow sources
   in its `.relay` folder and mutable run data in local application storage.
2. Open **Get started** to check installed coding agents. Use the suggested
   install or sign-in command if none is ready, then check again.
3. Choose **New workflow**, pick a starter, and describe a small task.
4. Select **Run workflow**. Review inputs and launch checks before submitting.

Watch jobs in Runs. Open a job to read its ordered steps. **Respond** opens an
approval request; the exact response is yours to choose. Pause holds new steps
while running work finishes. Cancel stops the run and retains its evidence.

Edit workflows visually, as YAML, or in Split mode. One Save writes the workflow
and edited local prompt files together. The Run workflow panel uses saved
sources; unsaved drafts stay available for later editing.
